# 资金潮汐分析法（FCTA）· 方法说明站

《资金潮汐——一套原创的资金流向分析方法》（作者：舟曙堂）的方法论公开站点。

## 内容

| 文件 | 内容 |
| --- | --- |
| `index.html` | 方法概览：为什么是潮汐、四个引力源、四相位模型、TCI 与潮汐罗盘、方法边界 |
| `concepts.html` | 核心概念词条：要素映射表、潮差与潮能、洋流/支流/回流/涡旋、三层水位、TCI、罗盘 |
| `author.html` | 作者与著作：舟曙堂（笔名）、著作结构、理论源流、原创声明 |
| `single.html` | 单文件整站（CSS 与封面图内联），可单独下载转发 |
| `资金潮汐分析法_单文件版.html` | 同 single.html 的中文文件名版本 |

## 发布

本仓库为纯静态站点，直接推送到 GitHub 后在 **Settings → Pages → Source 选 `main` / `/ (root)`** 即可发布。
或使用仓库外的一键脚本 `推送GitHub_一键.bat`（自动建仓库、推送、开启 Pages）。
